## 已确认的文档要求

1. 标题与正文统一使用黑色，通过字号、加粗和间距区分层级。
2. 开篇设置引言，从机械结构学习中的问题引入项目。
3. 设置目录及对应页码；第一版 Word、PDF 提供章节跳转。
4. 增加商业价值简述，说明教学、培训和定制等潜在应用方向。
5. 区分现有功能与后续规划；商业方向以可能的应用方式描述。

## 资料与版本范围

正文依据 2026 年 11 月 12 日已完成的网站检索、公开代码阅读和浏览器抽查整理。代码资料核对版本为 `88aa7e4e85ae77475229baf2b3a262532e9e7cc1`。后续代码可能已更新，归档保留本次说明书的事实依据。

`assets/lab.png` 与 `assets/exploded.png` 为项目网站截图；`assets/architecture.png` 为依据代码整理的架构示意。Markdown 内容便于 GitHub 阅读，正式分页与目录页码以 Word、PDF 为准。

本目录尚未包含赛事官方通知、评分规则、报名表和团队成员信息。目录名称用于资料归类，不代表已完成赛事报名或提交。后续可在此基础上补充比赛要求、申报材料与演示文稿。
