# 项目研究与事实核对

## 一、研究对象与来源

项目为 **啮合实验室 meshlab**，网站：https://slack-zh.github.io/meshlab/ ，仓库：https://github.com/Slack-ZH/meshlab 。

研究以项目首页、lab.html、公开参数、代码与仓库说明为依据；代码核对版本为 `88aa7e4e85ae77475229baf2b3a262532e9e7cc1`。本文件归纳说明书已使用的资料，不表示对后续版本重新完成全部验证。

## 二、核心事实

- 项目定位为机械原理学习与课程设计辅助的网页三维交互实验室。
- 当前完整可交互案例为 GL16 两级斜齿减速器，49 个零件实例。
- 首页五类机械档案属于原理示意；不能据此写成已完成五套完整三维实验。
- 现有能力包括旋转缩放、零件搜索选取、材料规格解读、箱体显示、爆炸展开、七步拆装、传动动画、工程资料下载和 AI 文字问答。
- 当前 AI 能结合项目及所选零件资料回答问题；自然语言直接操作模型、自动编排教学和工程仿真属于后续方向。

## 三、GL16 参数与计算

| 项目 | 数值 |
| --- | --- |
| 输入功率 | 1.5 kW |
| 输入转速 | 1,440 r/min |
| 中间轴转速 | 360 r/min |
| 输出转速 | 90 r/min |
| 两级传动比 | 4 × 4 |
| 总传动比 | 16∶1 |
| 总效率估算 | 0.96 |
| 输出转矩估算 | 约 152.8 N·m |
| 一级 / 二级中心距 | 80 / 112 mm |

公式：`i = (80/20) × (80/20) = 16`；`n输出 = n输入 / 16`；`T输出 ≈ 9550 × 1.5 × 0.96 / 90 = 152.8 N·m`。

网页慢放的基础输入轴转速约 12 r/min，设计工况的输入转速为 1,440 r/min；动画速度与设计值需要分别说明。

## 四、技术实现依据

| 模块 | 已阅读资料所对应的实现 |
| --- | --- |
| 页面 | 原生 HTML、CSS、JavaScript |
| 三维交互 | Three.js、OrbitControls、WebGL |
| 工程建模 | Python、CadQuery，导出 STEP、.mesh 和元数据 |

## 六、工程与表述边界

GL16 为参考工业结构的独立课程设计，模型简化螺纹、滚道、油封唇口及齿根过渡。三维动画按既定运动关系演示；现有资料用于教学与初步设计表达。工程制造和标准验算需要相应补充验证。

说明书中的商业章节属于潜在方向分析，未将市场规模、营收、付费客户或学习效果提升比例写成已验证成果。当前对话未提供这些数据。
