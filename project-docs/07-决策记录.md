## D05 · 优化优先级与范围收缩

- **日期**：2026-11-16。
- **取舍顺序**：参赛有效性与数据/费用安全 → 核心演示能走通 → 教学内容与数值解释正确 → 移动端/性能/外观 → 新功能。
- **含义**：这是后续问题排序规则，不代表其中已发现缺陷，也不构成修复授权。
- **删减项**：本轮不重写前端架构、不新增模型/仿真引擎、不自动安装 CLI、不生成全部 CAD/工程资源、不铺设九份空文档、不自动创建远端任务。

- **重议条件**：出现直接证据证明某项扩展是选定验收条件的必要前提，再单独调整范围。
- **状态**：生效。
