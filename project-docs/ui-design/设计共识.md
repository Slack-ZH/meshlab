# 首页 UI 设计共识

更新日期：2026-11-18。确认依据见 [讨论记录](讨论记录.md)；决定的先后关系见 [决策记录](决策记录.md)。本文件是当前有效状态，不把助手建议写成用户决定。

## 已确定

| 编号 | 有效要求 | 确认依据与范围 |
| --- | --- | --- |
| C01 | 设计对象是项目的整个首页 UI | U02、U03 明确纠正以零件或单台模型展示代替首页设计；目标截图已保存 |
| C02 | 保持机构展示的三维空间感与可切换体验；设备改为单台固定投影仪 | U05 原要求立体轮播；U20 明确否定三个设备轮转，“就一个投影仪行了”，以 C20 更新设备组织方式 |
| C03 | 重做机构目录与实验内容的组织和呈现 | U05 认为目录、实验区“太过生硬”“没有设计感”；不能继续沿用被否定的堆叠结果 |
| C04 | 整页内容顺序沿用此前规划 | U04 接受整页结构：导航 → 简短标题与介绍 → 立体机构轮播 → 完整机构目录 → 三步使用指南 → 关于与页脚。未确认各区具体布局 |
| C05 | 用户参与视觉决策，采用参考驱动与局部迭代 | U05 要求提高效率并亲自参与；U06、U07 同意建立按轮次推进的设计工作区 |
| C06 | 归档要求、参考、样稿、反馈与进展，明确状态 | U07 明确授权本次建档与项目入口、规则更新 |
| C07 | 已授权独立本地网页预览，用户在网页中参与调整；正式首页保持不动，不同步或部署 | U19 替代此前先不出稿限制，U20—U21 继续指导局部调整；不是正式首页接入授权 |
| C08 | 借鉴轻量的鼠标响应，投影轮播始终突出当前机构，避免一堆物体乱动 | U10 实际观察到 Lusion 鼠标推开物体并认可趣味性，但明确要求我们减轻反馈、保持主体焦点；未确定实现形式或数值 |
| C09 | 借鉴图片进入屏幕时的微小入场动画，提升动感 | U10 的用户观察与明确认可；未确定作用范围、位移方向、时长、缓动或重复触发规则 |
| C10 | 借鉴文字悬停产生位移的明确正反馈，按项目需要调整 | U10 的用户观察与明确认可；不要求原样照搬，具体文字范围与幅度仍待定 |
| C11 | 借鉴 Atlas 随滚动逐步展示机械结构的方式，用于首页实验介绍区 | U11 明确认可该方向与应用区域；只确认设计方向，未确认分镜、滚动参数或实现成品，不扩展至全部实验子页面 |
| C12 | 明确呈现下方投影器向上投射出机构的过程；切换时旧投影关闭、新投影启动，机构结构与细节清楚 | U12 明确指定的投影方向；部分确认原 P01/P02，不等于采用 Looking Glass 整站或其硬件效果；造型、材质、形成/消散形式和时序参数仍待定 |
| C13 | 借鉴目录与三维主场景联动、操作控件按需展开；不遮挡当前机构，不做得过于复杂 | U13 对 NASA 组织方式的明确认可及限制；未确认目录位置、控件数量、布局尺寸、具体联动形式或整站视觉 |
| C14 | 借鉴 OP–1 的控件器物感、简洁标识和排版留白；文字不能太小，必须清楚易读 | U14 明确认可这三个方向及可读性约束；未选择具体按钮造型、材质、字体、字号或配色 |
| C15 | 用户暂时没有具体概念，需要助手引导投影器搭建 | U15；由助手提供可理解的构成与具体推荐，用户判断取舍，不要求用户先独立给出整套设计 |
| C16 | 给用户做视觉选择时，配参考图等可见依据，帮助建立概念 | U16；不能只给抽象名称让用户想象。每次指出具体看哪个部位及怎样用于项目，仍聚焦一个局部、最多两个候选 |
| C17 | 投影器机身沿 B「集中发射的科幻底座」方向深化 | U17 回复“B”，对应 U16 外形参考图；确认底座观感与中央发射方向，不自动确认纯圆或多边形轮廓、颜色、光环数量、尺寸或动画 |
| C18 | 发射区采用①中央发光盘；底座必须简洁、不喧宾夺主 | U18：“选1，但是底座不要太复杂容易喧宾夺主”；选择发光盘，不照搬参考图的复杂外壳。底座服务机构展示，具体厚度、分缝、材质、亮度和启停节奏未定 |
| C19 | 直接提供可交互的网页版局部预览 | U19；可制作和检查本地样稿，仍不修改正式首页或发布 |
| C20 | 只用一台固定投影仪；本体需要设备结构，不能简化成盘子 | U20 否定 V01 的三盘轮转和空白圆盘造型；取代多展位设备轮转建议，不等于取消机构切换 |
| C21 | V02 本体可暂时保留，但仍需减弱设备主导、改进机构选择组织和投影动画 | U21：“勉强可以使用”；这是有限保留，不是验收。缩小设备是用户提出的思路，62% 及按需目录具体布局为助手 V03 提案，尚待反馈 |
| C22 | 先保留 V03 比例与目录，直接重做启停动画 | U24 明确选择该方向，更新 C21 的推进顺序；V04 当时作为提案，后续满意反馈见 C23 |
| C23 | V04 局部得到用户明确满意反馈，沿用启停方向继续深化 | U25“这一版我已经相当满意了”，更新 C22 的待反馈状态；不是整体首页验收，运动衔接仍需改进 |
| C24 | 可拖拽全方位观察，常态加入缓慢旋转，优化凝实与机械运动衔接 | U25；V05 实现这一轮需求。保持单台固定设备，只旋转机构；具体速度、停留和加速参数待用户反馈 |
| C25 | V05 先保留，当前继续打磨目录与背景 | U26；暂时保留现有交互，不等于完整首页验收 |
| C26 | 投影场景借鉴 NASA Eyes 的广阔感，减少 UI 及遮挡 | U26，延续 U13 的联动和按需展开；V06 的无框场景、侧栏、搜索和专注模式为助手具体提案，待用户评审 |
| C27 | V06 背景因太空旷、单调、缺少层次被否定，应补足远近关系 | U27 明确评价并澄清；后续 V07 反馈见 C28。目录和 V05 运动交互不因这次背景批评而改变状态 |
| C28 | 保留远近层次，去掉突兀框架和建模软件式地面线条；背景自然、精致且不抢机构 | U28；更新 C27 的具体方向。V08 连续曲面、柔光与淡落影为助手提案，待反馈；不扩大为目录、整体首页或正式接入已获认可 |

设计目标是更有设计感、精致并有辨识度的机械学习首页；“高端”“眼前一亮”是效果目标，不能据此自行选定深色主题、字体或特效数量。

## 待确认

| 编号 | 探索方向或问题 | 当前来源与下一步 |
| --- | --- | --- |
| P01 | 投影器主次关系与机构形成过程 | U25 对 V04 满意，U26 先保留 V05；U28 要求保留纵深但柔化 V07 背景，当前 V08 观感待反馈，机构保持主角 |
| P02 | 切换过程的具体时序及消散方式 | U12 已确认旧投影关闭、新投影启动；是否收回、扫描消散、启停时长与轮播位移怎样衔接仍待定，不将原助手细化流程整体视为定稿 |
| P03 | 底座具体轮廓与比例、是否保留卡片轮廓、投影材质 | U17 已选 B 总体方向，U18 限定简洁且不抢机构焦点；低矮机身、减少分缝等是助手细化建议，纯圆或圆角多边形等细节仍未定。机构结构与细节必须清楚，并继续保留立体轮播 |
| P04 | 参考方向的具体落地范围 | 已确认 C08—C14 的方向，均非整站采用；各局部怎样组合、如何适配机构内容仍待确认，优先级建议见阶段汇总 |
| P05 | 目录与场景的具体位置及布局 | U26 授权打磨目录并减少遮挡。V06 为可搜索缩略图目录、桌面侧栏/小屏上方排布，展开时给场景留空间；具体位置、样式与尺寸待用户反馈 |
| P06 | 实验介绍区的信息层级与具体布局 | U11 已明确 C11 用于首页实验介绍区；内容、布局与分镜尚未决定，不能据此自动修改所有实验子页面 |
| P07 | 颜色、字体、具体字号、控件形状/材质、玻璃程度、光效、布局比例、转场时间 | U14 已确认器物感、简洁标识、留白及文字清楚；具体视觉规范仍待决定，不自动采用 OP–1 原有字体或小字号 |
| P08 | 手机、键盘、减少动态与性能适配的具体方案 | 后续原型/实现需验证；不能用桌面静态截图代替这些结果 |
| P09 | C08—C10 的交互细化 | U25 已明确拖拽模型观察和常态旋转；V05 的 80 秒一周、松手停留 4 秒为助手参数。图片入场、文字悬停等其他范围与节奏仍未定 |
| P10 | C11 的滚动展示细化 | 选用机构、展示阶段、结构变化、镜头/文字衔接、滚动距离、回滚行为与适配方案均未决定；“原理 → 拆装 → 调参”等顺序仍属助手候选，不自动作为定稿 |
| P11 | C13 的联动与控件细化 | 分类/检索方式、选中如何更新场景及文字、镜头是否移动、哪些控件常驻或展开、展开位置和收起方式均未定；须满足不遮挡当前机构、保持简单的已确认约束，不扩展实验子页面实施范围 |

待确认项见 [阶段汇总](阶段汇总.md)；当前实际实现和验证边界见 [002 迭代](迭代/002-投影轮播网页预览/记录.md)。局部制作已获 U19 授权并启动，设计是否采用由用户决定。

## 已否定或失效

| 编号 | 结果 | 否定内容与后续约束 |
| --- | --- | --- |
| N01 | 初组三版首屏方向失配，未采用 | 用户 U02、U03 纠正：要磨项目首页，助手过度聚焦单台模型。保留档案，不作为首页视觉基线 |
| N02 | 六版首页被整体否定 | 用户 U05 对整组结果明确否定。深蓝玻璃、冰白玻璃、石墨银、工程蓝图、暖白图鉴、交互学习馆均未获确认 |
| N03 | 反复抽象描述愿望，再批量生成整页的协作方式失效 | 用户认为效率太低；改为具体参考、单一区域、最多两个局部方案、用户参与调节与反馈 |
| N04 | 被批评的机构目录和实验区堆叠方式 | 不以更换配色继续提交相同结构；需重新组织内容与交互 |
| N05 | V01 圆盘底座、三个盘子轮转与生硬投影动画 | U20 明确否定，V01 保留归档；V02/V03 已改为单机设备，动效仍待重做 |
| N06 | V06 当前背景效果 | U27：“太空旷、单调，缺少层次”“感觉很难看”。该结论限于背景，不扩大为 NASA 参考方向或整套目录/UI 被否定 |
| N07 | V07 突兀框架与工程式地面线条 | U28：“后面的框架太突兀，地面线条也有点像建模软件”；保留远近层次目标，不按原样继续强化结构和网格 |

N02 不代表 C02 的立体轮播被否定，也不代表 C04 的整页内容顺序被撤回。初期参考网站没有被用户逐站否定，不能把样稿失败推成参考网站禁用。

## 权限和确认

- 用户决定保留、调整、否定和最终验收；执行者负责在当前授权内研究、制作和记录事实，不代替用户确认设计。
- 浏览/切换过“机械剧场”“交互学习馆”“深蓝玻璃”等样稿是交互痕迹，不构成设计选择。以 U05 的显式反馈为准。
- 当前进入独立网页迭代，U19 授权预览并取代 U14 的先不出稿限制；U29 进一步授权本轮 UI 归档并上传独立分支，不合并 main、不部署、不修改正式首页或实验功能。U21 暂时保留本体，U24 暂时保留比例/目录并直接进入动画局部，均不视为最终验收。
- 后续若新要求改变已有决定，追加决策并链接被替代项，更新本文件；已有授权范围内的例行工作不重复请求确认。
