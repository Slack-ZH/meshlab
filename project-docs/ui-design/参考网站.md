## 如何记录用户选择

用户评价后更新对应条目的状态，并追加决策记录：

- 取用的具体页面、位置或状态，例如“R04 的目录与主视图区关系”。
- 保留什么、不要什么，以及采用原因。
- 是确定内容结构、视觉风格还是交互节奏；不同层次分别记录。
- 对应截图、录屏或局部样稿路径，以及尚未验证的内容。

来源统一保存公开网址、本地截图及捕获日期。原始抓取 JSON 含临时签名截图地址且包含大量无关页面文本，本次未复制；可追溯材料见 [归档清单](归档清单.json)。第三方截图用于参考和评审，正式页面使用项目自己的品牌、模型和内容；具体借用范围尚未确定。
