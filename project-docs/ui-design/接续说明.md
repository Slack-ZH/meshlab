## 启动与预览

当前实现：`project-docs/ui-design/迭代/002-投影轮播网页预览/dist/`。

先检查 [本地预览](http://127.0.0.1:8092/) 是否仍运行；不要依赖旧进程或浏览器标签编号。需要重启时在项目根目录执行：

```powershell
node "project-docs/ui-design/迭代/002-投影轮播网页预览/serve.mjs"
```

仅绑定 `127.0.0.1`。U29 归档时已把七个运行依赖冻结在迭代目录的 [shared/](迭代/002-投影轮播网页预览/shared/README.md)，服务读取这些副本，不再依赖未提交的实验目录。无需安装依赖、公开端口或联网下载 Three.js。模块依赖 HTTP 路由，不能双击 HTML；修改后刷新，无热更新。调节值是会话状态，不能把点击/滑块位置当作用户设计决定。
