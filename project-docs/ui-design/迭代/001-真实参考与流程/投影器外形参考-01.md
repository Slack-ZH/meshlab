## A：精密仪器式机身

![Teenage Engineering TX–6 产品图](https://teenage.engineering/_img/623a2ed378b3260004e06d72_512.png)

- 来源：[Teenage Engineering TX–6 官网](https://teenage.engineering/products/tx-6)。这是一件音频设备，图片用于外壳与控件细节参考，不是现成投影器。
- 重点看：实体外壳的边缘、紧凑设备的厚度、控件与标识的关系。
- 助手建议的转化：采用低矮矩形机身，把顶部大部分区域留给发射盘，前侧保留少量清楚的标识和状态信息。图中的密集旋钮不是建议照搬的控件清单。
- 倾向：精密、可信的实验仪器感。矩形长宽比、颜色、表面处理均未确认。

## B：集中发射的科幻底座

![t.flores 的全息投影器概念模型](https://media.sketchfab.com/models/ca0a3bc92a3d4a3f9b0fa19cbc73b420/thumbnails/8e366d10738f41c485cdf74878523232/3bf1d7597145488ba02056200592319e.jpeg)

- 来源：[t.flores · Hologram projector with hologram / Sketchfab](https://sketchfab.com/3d-models/hologram-projector-with-hologram-ca0a3bc92a3d4a3f9b0fa19cbc73b420)。这是科幻三维概念作品，不是真实设备性能证明。
- 重点看：中央发射区、围绕中心的底座，以及上方留给投影的空间。此图外壳带多边形结构，并非严格的纯圆机身。
- 助手建议的转化：简化为低矮圆形或圆角多边形底座，主体上方展示单个机构；装饰光环和附加面板大幅减少，保持机构细节清楚。
- 倾向：投影来源更直观，科幻感更强；具体光效和底座轮廓仍待选择。
