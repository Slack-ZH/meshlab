## 用户反馈

完整来源见 [U02—U05](../../讨论记录.md)。关键内容：

- 第一组：“我要的不是零件的，是项目主页的ui设计。”
- 第二组：“全都是屎”，并指出这种反复“许愿”的交互效率太低。
- 明确保留立体 3D 轮播，希望进一步探索投影形式。
- 目录内容堆叠生硬，实验区缺乏设计感，需要重新组织。

## 当前结论

- 不再沿用任何一版作为已获准的整体设计；浏览样稿的选中状态不改变此结论。
- 保留整页内容顺序这一单独被接受的结构要求，也保留立体轮播这一被再次强调的设计要求。
- 不将“静态卡片换配色”作为新一轮交付；后续应围绕具体参考和局部交互深化。
