Mobile and hover not inspected.

## Adaptation

The sixth concept, 交互学习馆, combines the first source's unobstructed colored diagrams and small local control with the second source's subject-based entry points. It uses original mechanism drawings and MeshLab copy. No third-party logos, photographs, interface code, usage statistics or endorsement claims are reused. Its green palette, split composition and sizes are proposed choices, not extracted source values.

## Six directions

1. 深蓝玻璃: retain the user's screenshot's floating navigation and spatial card rail; reduce visual haze and emphasize the selected card.
2. 冰白玻璃: asymmetrical editorial hero, pale layered cards, roomy four-column directory.
3. 石墨银: dark graphite, strong typography, horizontal exhibit strip and restrained yellow accent.
4. 工程蓝图: cobalt drawing surface, line dividers, measured diagram framing, dense row directory.
5. 暖白图鉴: ivory paper, serif display typography, overlapping folio cards and editorial directory.
6. 交互学习馆: the sourced learning-interface adaptation described above.

All share navigation → headline and mechanism showcase → categorized directory → three-step usage → about and footer. Catalogue entries are representative UI samples. Interactions are local to the mockup. Production links, real AI, voice and experimental mechanics are out of scope.
