## 本地实现规范（助手提案，非 NASA 提取数值）

- 背景 `#070c13`，正文 `#e8eef3`，次要文字 `#91a2b3`，强调 `#a6d8ef`，边线白色约 12% 透明。
- 字体沿用本机 Segoe UI / Microsoft YaHei；标题桌面 34 px、手机 25 px；目录标题桌面 16 px、窄手机 13 px，顶部按钮 12—13 px 且保留 44 px 点击高度。未提取 NASA 字体文件。
- 顶部桌面 80 px、手机 72 px；宽桌面目录 304 px，设置面板 324 px；760 px 以下上下排布，展开时增加场景容器高度。
- 中央保留单台固定投影仪、V05 拖拽/自转、V04 启停和 GL16 材质；只调整场景取景空间与背景。
- 无图片下载。机构缩略图使用本地原创 SVG 示意，远景点与地面由 Three.js 生成；不使用 NASA 图像作为产品背景。

## V07 · 背景反馈后的修订（U27，2026-11-18）

用户否定 V06 背景，澄清问题是太空旷、单调、缺少层次。目录/UI 的状态没有因此改变。

参考截图中的轨迹和天体位置提供了远近参照；V06 只保留了暗色与大留白，没有足够空间线索。这是助手对失配的分析。V07 改用机械展场的地面与结构轮廓提供参照，不声称 NASA 网页存在这种建筑场景。

- 近景：低亮度环形地面刻线、大尺度地面分缝；不是额外设备或旋转底座。
- 中景：投影仪周围柔和光区与原有阴影，让设备有落点。
- 远景：缩小并推远的低亮度结构轮廓和断续轨道线，保持模型周围留白。
- 地面在视窗边缘渐隐，避免露出三维画布裁切边界。
- 环境完全静态，不增加持续飞行粒子或闪烁。V05 机构交互/运动不变，V06 目录和收纳布局保留为未定稿实现。
- “观看设置 → 背景对比”可切换新环境和 V06 对照；对照不是恢复为已接受方案。具体环境亮度、刻线和轮廓仍待用户反馈。

## V08 · 柔化纵深（U28，2026-11-18）

用户保留远近层次，但指出 V07 框架突兀、地面像建模软件。显性框架与工程标线不再作为当前默认；它们只保存在历史版本及对照项中。目录与 V05 交互保持原状态。

本轮是根据用户反馈进行的本地设计修订，没有新增外部参考抓取。助手提出接近产品摄影无缝背景的连续空间：地面圆滑上卷为远景，在同一表面上用法线和宽幅侧向柔光表达距离，而不是加新的建筑或装饰物。

- `soft-environment.mjs`：哑光底色 `#080e15`、粗糙度 .93、金属度 .03；连续曲面半径 14 个场景单位。具体数值为助手实现参数。
- 两侧宽幅明暗变化、局部地面光区、极轻静态颗粒；透明度边缘渐隐，使背景延伸到页面而不出现硬画布边界。
- 保留原机构照明与 GL16 材质；只将柔和背景的地面阴影透明度设为 .13，V07 对照仍为 .22。
- 默认无网格、刻线、环线、结构框架、星点或环境动画，机构继续承担画面主要动态与高光。
- 同姿态切换“柔和空间 · 新 / V07 层次展场 · 对照”，便于用户比较。V08 自然度和明暗效果仍待评价；实现和浏览器检查不等于设计验收。
