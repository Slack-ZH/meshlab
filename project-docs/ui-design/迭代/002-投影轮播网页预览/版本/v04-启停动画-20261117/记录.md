## V03 的可交互范围

- 固定一台设备，切换机构时不移动或轮转投影仪。
- 默认展示机构；“设备近景”用于检查本体，支持拖动旋转和双击复位。
- 机构目录默认收起：桌面展开为左侧独立栏，三维视口重新排布；手机目录处于正常文档流，选择后收起。
- 常驻快捷操作为下一机构、暂停、重播；支持键盘左右切换。点击机构可选中零件，能拆开观察并恢复。
- 设置面板按需展开：设备比例 45%—80%（默认 62%，相对 V02）、光强、速度、减少动态。
- 机构保留实体冷灰材质和结构细节；投射光在外层表达设备状态。

## V04 · 启停动画（U23—U24）

- **目标：** 保留现有主次与目录，只打磨启停动画的层次和节奏，替代 V03 的横向硬裁切显现。
- **依据：** U12 的中央向上投射、旧关闭新启动、结构清楚；U20/U21 对生硬动画的否定；U24 明确本轮直接重做动画。没有引入新外部参考或把新参数写成用户决定。
- **授权对象：** 摩擦轮、齿轮齿条两个既有模型，执行者为本会话助手；没有新增机构，不改其他人的机构实现。
- **实现：** 0.78 秒消散 → 0.12 秒关闭间隙 → 0.44 秒预热 → 0.40 秒光束上行 → 1.32 秒轮廓凝实 → 0.56 秒光效回落；完整切换 3.62 秒，首次启动 2.72 秒，可通过原速度控件调节。所有参数为助手提案。
- **表现：** 发射腔内光晕收聚，光束从实际盘面向上延伸；轮廓比表面提前出现，渐变光点过渡到 GL16 实体材质；稳定后回到原实体呈现；关闭时反向消散。模型阴影使用相同显现掩膜。无多设备轮转、机械件飞散或新机构。
- **交互：** 增加默认收起的“分解查看启停”，可拖动进度停在任意阶段；重播恢复完整过程并将机构滚入视野。原比例、目录、光强、速度、暂停、选中、拆装保留。减少动态时取消上行与轮廓光效，以 0.32 秒淡出/淡入切换。
- **用户反馈：** 本轮明确的只有“比例和目录先保留，直接重做动画”；V04 观感尚未收到用户评价。
- **当前结论：** 局部实现完成；本地检查通过；待用户验收。不能声称已解决用户所说的生硬感或科技感不足。
