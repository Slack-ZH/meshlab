# V06 · 目录与开放场景

日期：2026-11-17—18（Asia/Hong_Kong）。本轮仅为本地首页局部设计；不接入正式首页。

## 参考与证据

- 来源：[NASA Eyes on the Solar System](https://eyes.nasa.gov/apps/solar-system/)。
- 实际查看：[2026-11-17 归档截图](../../参考素材/网站/real-nasa-eyes.png)，不是本轮新抓取。截图显示铺满画面的黑色三维空间、细小星点、轨迹线、左侧故事栏、右上菜单及边缘工具。
- 本轮 Firecrawl 新抓取因额度不足未执行；不把旧图说成实时验证，不重试扣费，也不归档账户或账单链接。
- U13 已认可目录/场景联动与按需控件；U26 新要求广阔感与减少 UI。借鉴的是场景优先和边缘组织，不照搬 NASA 整站、标志、行星纹理、轨迹或功能。

## 观察与提案分开

| 项目 | 参考中观察到 | MeshLab 本轮提案 |
| --- | --- | --- |
| 空间 | 黑色连续背景，无中央场景卡片边框 | 深蓝黑背景延伸到窗口边缘，稀疏远景点、低亮度地平线，去密集网格 |
| 页面结构 | 标题/菜单在顶部，工具在边缘 | 顶部品牌与目录/设置/专注；机构摘要在左下，少量快捷操作在右下 |
| 目录 | 左侧垂直条目区与主场景相邻 | 可搜索机构侧栏，真实联动两个既有模型；展开为其预留场景空间 |
| 控件 | 右侧工具与底部时间控制 | 拆装、重播、近景、调参、启停分解收进一个按需设置面板 |
| 专注 | 截图中大部分画幅是场景 | 专注模式保留场景与退出按钮，Esc 退出 |

上述是基于截图的布局观察，不是对 NASA CSS、响应式断点或动效的测量。

## 本地实现规范（助手提案，非 NASA 提取数值）

- 背景 `#070c13`，正文 `#e8eef3`，次要文字 `#91a2b3`，强调 `#a6d8ef`，边线白色约 12% 透明。
- 字体沿用本机 Segoe UI / Microsoft YaHei；标题桌面 34 px、手机 25 px；目录标题桌面 16 px、窄手机 13 px，顶部按钮 12—13 px 且保留 44 px 点击高度。未提取 NASA 字体文件。
- 顶部桌面 80 px、手机 72 px；宽桌面目录 304 px，设置面板 324 px；760 px 以下上下排布，展开时增加场景容器高度。
- 中央保留单台固定投影仪、V05 拖拽/自转、V04 启停和 GL16 材质；只调整场景取景空间与背景。
- 无图片下载。机构缩略图使用本地原创 SVG 示意，远景点与地面由 Three.js 生成；不使用 NASA 图像作为产品背景。

## 检查与未决项
