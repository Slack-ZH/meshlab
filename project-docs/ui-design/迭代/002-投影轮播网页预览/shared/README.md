# V08 运行依赖快照

2026-11-18，依据 U29 的归档上传要求，原样复制当前预览实际使用的七个模块。`manifest.json` 记录项目内来源、大小和 SHA-256；模型实现没有修改。

`serve.mjs` 只从本目录的固定白名单提供 `/shared/` 资源，因此拉取此分支后不依赖开发者尚未提交的实验文件。启动仍使用 Node.js，无需 npm 安装、联网下载或公开端口。

Three.js r170 与 OrbitControls 按 MIT 许可分发，保留原文件版权声明，许可见 [THREE-LICENSE.txt](THREE-LICENSE.txt)。其他五个文件来自本项目的 GL16 公共实现、摩擦轮和齿轮齿条实验。这些是用于重现 UI 样稿的快照，后续机构开发仍在原实验中进行。
