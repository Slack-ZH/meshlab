## 后续追加方法

每条新记录写清：日期、状态、具体决定、用户确认来源、对应样稿/截图、理由、验证限制、影响的旧决定。

- 改变既有决定时保留原记录并标记“由 Dxx 替代”；更新设计共识与总入口。
- 助手建议先标为待确认；程序检查通过只更新检查状态。
- 用户对单个区域的确认只覆盖该区域，不扩展为整页、全部机构或上线授权。
- 用户验收由用户决定。未实际检查过的项目保留“未验证”，不能写成通过。
