# 首页 UI 阶段汇总与下一步建议

更新日期：2026-11-18。U14—U18 的参考结论保留；当前仍是单台固定设备的本地预览。**V05 先保留；U28 要求保留纵深但去掉 V07 突兀框架和工程式地面线条。V08 用连续曲面、柔光与淡落影替代，具体提案待反馈。正式首页不改、不同步或部署。** 当前实现见 [002 迭代](迭代/002-投影轮播网页预览/记录.md)。

## 已确定的设计方向

| 部分 | 已确认内容 | 来源与边界 |
| --- | --- | --- |
| 首页结构与轮播 | 保留并优化立体 3D 轮播；内容顺序为导航 → 简短标题与介绍 → 立体机构轮播 → 完整机构目录 → 三步使用指南 → 关于与页脚 | C01—C04；确认内容顺序，不是具体布局；实验介绍滚动段落与此结构的衔接仍需细化 |
| 交互反馈 | 鼠标反馈轻、当前机构突出；图片有微小入场动画；文字悬停有位移正反馈；按项目需要调整 | Lusion / C08—C10；避免一堆物体乱动，不原样照搬整站 |
| 投影呈现 | 明确看到下方投影器向上投射机构；切换时旧投影关闭、新投影启动；结构与细节看得清楚 | 用户在 Looking Glass 评审后明确的方向 / C12；不是认定该网站有完全相同的现成轮播 |
| 投影器机身 | 采用 B「集中发射的科幻底座」方向 | U17 / C17；具体轮廓、材质与光效未定 |
| 发射区与主次 | 采用①中央发光盘，底座简洁、机构保持主角 | U18 / C18；不照搬参考图的复杂装甲或外挂 |
| 实验介绍 | 随滚动逐步展示机械结构 | Atlas Motion / C11；用于首页实验介绍区，不扩展到全部实验子页面 |
| 内容与操作组织 | 目录与三维主场景联动，控件按需展开；不遮挡当前机构，保持简单 | NASA Eyes / C13；目录位置、控件数量及具体展开布局未定 |
| 控件与文字 | 借鉴器物感、简洁标识、排版留白；文字不能太小，必须清楚 | OP–1 / C14；未确定字体、字号、按钮形状或配色，不复制产品全部控件 |
| 协作方式 | 真实参考 → 单一区域 → 最多两个局部方案 → 用户调节与反馈 → 确认后扩展，持续归档 | C05—C07；旧三版和六版样稿维持未采用/已否定状态 |

共同约束：所有表现都围绕当前机构；动效应轻而有反馈；结构、文字和操作都清楚；不回到生硬堆叠的展示方式。没有采用任何参考网站的整站视觉。

## 还需要用户确认什么

### 优先在投影轮播局部确定

1. **投影器细节与轮播载体。** B 科幻底座、①中央发光盘及底座简洁的约束已确认；具体轮廓与比例、盘面细节、是否保留部分卡片轮廓仍待确认。
2. **机构与投影光的材质关系。** 实体感主体、半透明或其他表现怎样平衡？光束、边缘光、离台高度应有多明显？清晰度约束已确定。
3. **切换和鼠标响应的观感。** 旧投影怎样关闭，新机构怎样形成；轮播移动与启停怎样衔接；鼠标主要影响机构、灯光还是设备；是否轻、稳、及时。
4. **局部构图与信息位置。** 中央机构多大、侧面待机展位露出多少、名称与进入入口放在哪里；当前主体不能被遮挡。

### 随后按区域确认

- **整页视觉规范：**深浅背景、主色与强调色、中文字体气质、控件轮廓、材质强度和留白比例。
- **目录与控制区：**具体位置、分类方式、选中与主场景的联动、常驻和展开的控件及收起方式。没有确认固定左侧索引。
- **实验介绍滚动段落：**使用哪个现有机构、展示几个阶段、如何安排结构变化与说明、如何接入已确认的整页顺序。

用户主要确认看得见的选择与体验，不需要一次决定所有技术参数。字号、动画时长等后续可由执行者提出初值，再依据效果调整；不能将未提出的数值写成用户决定。手机、键盘、减少动态与性能适配由后续实现验证，不以静态样稿代替检查。

## U14 当时的局部优先级建议（U19 后已启动）

**先打磨“中心投影展台 + 从一个机构切换到另一个机构的完整过程”。**

理由：这是用户最想保留并深化的首页记忆点，也能同时检验立体轮播、投影设备的器物感、结构清晰度及轻量反馈。局部确认后，它的材质、控件和文字规则才适合扩展至目录与介绍区。

后续局部范围建议：

- 使用两个现有机构，不新建机构；呈现当前展台与相邻待机展台的空间关系。
- 包含设备待机、向上投射、机构展示、轻量鼠标响应、旧投影关闭和新投影启动。
- 带上必要的机构名称和进入入口，检验文字可读性与主体留白。
- 第一轮最多比较两种投影器/展台形态，使用相同机构、视角与切换逻辑，让差异可判断；其后再单独调整材质或节奏。
- 有必要时提供少量直观调节项，如投影光强、展示大小、切换快慢；具体控件尚未制作。

判断局部是否值得继续的标准：一眼看清当前机构；能看懂投影从哪里来及启停过程；操作有轻量反馈；机构细节和文字清楚；整体不杂乱、不拖沓。标准是建议的评审问题，不是已完成验收。

**U14 时没有启动这一步；U19 已授权并启动局部网页预览。** 以下 U15—U18 为引导过程历史，当前版本与反馈见 U19—U21 和 002 迭代记录。

## U15：引导式搭建的第一步（助手推荐，未定稿）

用户没有具体概念，需要助手给出明确推荐并引导判断。先把投影器分成四部分：

| 部分 | 初始建议 | 目的 |
| --- | --- | --- |
| 设备机身 | 低矮矩形仪器，边角适度圆润，顶部留出清楚的发射区 | 承接器物感，视觉上稳固，并让上方机构成为主体 |
| 发射区 | 顶部中央可辨认的发射盘或透镜，发光来源明确 | 用户能看懂投影从哪里产生 |
| 投影光 | 从发射区向上延伸的轻量光束，形成时清楚、展示时收敛 | 表达设备正在投射，保留机构细节 |
| 悬浮机构与状态信息 | 上方机构清楚可读，简短名称与状态标识留在外围 | 同时满足机构展示和操作理解 |

这不是四项需要用户同时决定的选择。**本轮只讨论机身外形**：低矮矩形设备（助手推荐）或圆形投影底座（另一候选）。前者偏精密仪器，易安排前侧标识与状态灯；后者更突出光从中心发出的视觉关系。未固定颜色、材质、尺寸或圆角参数。

后续逐步讨论顺序：外形 → 向上形成/关闭方式 → 机构与光的材质关系 → 轮播切换 → 轻量鼠标反馈与标识。每次由助手提出推荐，用户指出喜欢或不喜欢的部分；需要样稿时仍限定局部和最多两种同条件对比，不恢复批量整页出稿。

## U16：给选择配上可见参考

用户表示纯文字选项无法建立概念。以后每轮以参考图或短演示开头，明确“看哪里、怎样用于我们的投影器”，再给推荐和一个问题。允许只认可某个部位或混合，不要求整件照搬。

本轮新增 [投影器外形参考 01](迭代/001-真实参考与流程/投影器外形参考-01.md)：A 看精密音频仪器的实体外壳和标识；B 看科幻概念底座的中央发射区与上方空间。两张图是帮助建立概念的外部参考，未形成用户认可的新样稿。

## U17：已选 B，接着只看发射区

用户回复“B”，确定科幻投影底座方向。上文 U15/U16 的矩形优先或混合建议保留为讨论历史，后续以 B 为基线。下一项配图见 [发射区参考 02](迭代/001-真实参考与流程/投影器发射区参考-02.md)：①中央发光盘（助手推荐）；②分层悬浮光环。未替用户选择细节，也未制作样稿。

## U18：中央发光盘与简洁底座

用户选①，并明确底座不能太复杂、喧宾夺主。当前方向为“B 科幻底座 + 中央发光盘 + 简洁的辅助角色”。助手建议低矮机身、少量分缝、集中出光；这些尚未形成具体定稿。下一项适合看机构向上形成与关闭的动态参考，不再重复让用户选择发射区，也不要求用户先决定细小装饰参数。本轮未制作新参考或样稿。

先不出稿的限制已被 U19 更新。V01 三圆盘轮转被否定，V02 改为单机，V03 处理主次和目录，V04 打磨启停，V05 增加观察和运动衔接。U26 要求 V05 先保留；U27 否定 V06 背景空旷单调；U28 要求保留纵深但柔化 V07 突兀结构与工程标线。当前 V08 只改柔和背景，可与 V07 对照；目录与其他 UI 状态不因此自动改变，局部提案仍待反馈。
