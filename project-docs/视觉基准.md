## 实现与取景

- **构图**。沿用 GL16 的三分之四斜视、浅网格和落影。根据实际包围盒适配画幅和控件留白，分离方向应能看懂装配轴线和顺序。薄型传动可以用较浅的斜角保留接触面，正视和俯视供检查对齐。
- **材质与灯光**。采用冷灰机械件配色，区分齿轮、轴、轴承、紧固件、铸造支承和哑光胶面。沿用 sRGB、ACES Filmic、1.25 曝光、半球光、主光与冷色补光。参数以原包 JSON 为准，灯光范围按模型比例调节。
- **交互**。蓝色发光 `#226ad8`、强度 `0.32` 用于当前选中件，切换选中时恢复前一件的基础外观。支承透明模式取 16% 不透明度。自由旋转、缩放与传动演示沿用各实验控制。
- **复用**。Three.js 实验从 [reference-stage.mjs](../meshlab/dist/assets/reference-stage.mjs) 复用布光、地面、材质、取景和高亮。自行车链传动与摩擦轮传动已接入。机械尺寸、接触关系和运动参数由各实验自身的模型定义。
