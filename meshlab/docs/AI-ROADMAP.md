# 从问答到自然语言控制三维模型

> 2026-10-28 更新：按网站维护者要求，暂时关闭邮箱验证。注册或邮箱密码登录后即可聊天，不自动发送验证邮件；每账号每日 2 元预算不变。恢复时将 wrangler.jsonc 的 REQUIRE_EMAIL_VERIFICATION 改为 "true" 并重新部署 Worker，前端会自动采用云端策略。以下涉及强制验证的步骤仅在重新开启后适用。

按每一步都能实际验收的方式推进。

## 第一步：本地问答（本次完成）

在现有模型旁加入 DeepSeek 聊天，支持流式输出、连续追问、选中零件上下文、停止、重试和新对话。后端保管密钥，前端只负责消息和展示。原来的零件说明放在相邻页签。

验收：选中输入齿轮轴，询问“这个零件有什么作用？”，再追问“它连接哪一级？”。AI 能引用本项目资料；拆装、播放和下载继续可用。真实问答及浏览器回归检查已通过。

## 第二步：部署可用的聊天服务（云端问答已验证）

保留 GitHub Pages 网页，配置 Cloudflare 后端、DeepSeek 密钥、Firebase 邮箱登录、允许的网站地址与账号预算，验证线上连续聊天和错误提示。

2026-10-28：Worker 已部署，HTTPS、跨域预检与真实 DeepSeek 回答已验证。新增邮箱注册、邮箱验证和登录，取消共享口令；每账号每日 2 元保守预算由 Durable Object SQLite 持久记录。预算并发、账号隔离、零点重置和伪造凭证拦截测试通过，真实收件箱验证由邮箱本人完成。

验收：从 GitHub Pages 正式地址登录并验证邮箱，发送问题收到真实回答和预算更新；浏览器和源码中不包含 DeepSeek 密钥。Firebase 的公开 Web 配置可存在前端。

## 第三步：自然语言控制现有模型

先支持有限动作：选中零件、切换视角、展开/复原、播放/暂停、切换拆装步骤和演示速度。

AI 提议结构化动作；程序检查动作名称、零件 ID、数值范围后调用已有控制函数。执行结果回传聊天，并提供复原入口。禁止让模型生成任意 JavaScript 后直接执行。

验收：“选中输出轴，切换俯视图，再全部展开”产生可以看见的相应动作；无法识别的零件和超范围参数会给出解释，不破坏模型。

## 第四步：分步教学动画

支持“演示动力如何传递”这类多步指令，将高亮、视角、讲解和播放编排成可暂停、重播的教学过程。先从一套固定模板开始，再增加可编辑的步骤。

验收：每一步的文字、零件高亮与动画顺序一致，暂停和复原可靠。

## 第五步：参数计算与工程仿真

先接传动比、转速、转矩等确定性计算工具；AI 负责收集输入、解释结果。再按需求选择动力学、应力或碰撞仿真引擎，明确材料、载荷、边界条件、单位和结果适用范围。

验收：数值来自计算工具或仿真引擎，可复算且显示输入条件。三维动画展示与工程仿真结果分别标明。具体仿真范围和引擎在这一阶段再确定。
