## RESULT.md 内容

- 任务编号、任务单链接及版本、草稿 PR 链接、实际测试的代码 commit SHA。
- 改动摘要及任务单各项验收结果。附实际执行的命令或复现步骤、期望值和实测值，以及失败或未运行项和原因。
- 任务单指定的截图或测试报告。截图可提交到任务子目录，也可附在草稿 PR 后在报告中逐一链接。标明页面、视口尺寸、交互状态，参数对比图附参数组。
- 采用第三方模型或素材时，列出来源与授权依据。

返工时更新同一份报告及 PR 内容。回传时只提交本任务的结果文件。此目录公开，证据仅包含可公开内容。
