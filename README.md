# 啮合实验室 · meshlab

> **W 的 11 项整合分支**：基于最新主线保留原有 44 项，统一首页目录现有 55 个实验。交接范围、预览方法和检查结果见[整合说明](meshlab/docs/W11-INTEGRATION-20261117.md)。此分支尚未合并或部署，下方在线体验仍对应已发布主线。


啮合实验室是一个面向机械课程学习的三维交互网站。以 **GL16 两级斜齿减速器**为例，你可以观察零件如何装配，沿着输入轴、中间轴和输出轴追踪动力传递，再用图纸、BOM 和设计说明书核对结构与参数。

**[在线体验](https://slack-zh.github.io/meshlab/)** · **[进入 GL16 实验室](https://slack-zh.github.io/meshlab/lab.html)** · **[查看工程资料](https://slack-zh.github.io/meshlab/lab.html?view=engineering)**

**[进入汽轮机实验](https://slack-zh.github.io/meshlab/turbine.html)**：无公共底座的封闭汽缸配有进排汽口，可开盖观察和分步拆装。在模型下方调整级数、叶片数、末级叶高、根部轴向弦长与轮毂直径，三维结构即时更新；AI 问答会附带当前参数和选中零件。

汽轮机采用通用教学叶型，逐级尺寸和间隙规则见[叶型校准说明](meshlab/dist/turbine/GEOMETRY.md)。工况、流量和指定效率决定当前功率估算；几何尚未耦合逐级气动损失，不具备制造级设计或校核效力。

**[进入摩擦轮实验](https://slack-zh.github.io/meshlab/friction.html)**：改变两轮直径、轮宽与输入转速，模型自动保持相切，按理想无滑动关系反向转动。下方可调压紧力、摩擦系数和负载转矩，比较牵引力上限并查看打滑风险；页面沿用减速器的视图、拆装、零件目录和 AI 布局。

摩擦轮入门顺序：播放观察 → 调轮径比较速比 → 增大负载观察容量超限 → 展开并选取零件 → 向 AI 追问。无滑动理论速度不等于超限后的实际速度；模型未求解滑移率。详见[模型与计算说明](meshlab/dist/friction/DESIGN.md)。

**[进入单级直齿齿轮实验](https://slack-zh.github.io/meshlab/spur.html)**：调整两轮齿数、模数与齿宽，三维轮齿和中心距同步更新；播放观察外啮合反向传动，设置输入转速、转矩与效率，比较输出转矩和功率。视图、拆装、零件目录和 AI 布局继续沿用减速器。

直齿轮入门顺序：播放观察 → 对比 20/40、30/30、40/20 齿 → 改变模数检查尺寸与速比 → 调整转矩和效率 → 选取零件向 AI 提问。模型采用 20°、零变位教学几何，未进行制造与强度校核；详见[齿轮模型说明](meshlab/dist/spur/DESIGN.md)。

**[进入带惰轮齿轮列实验](https://slack-zh.github.io/meshlab/idler.html)**：三个齿轮经两次外啮合，首尾同向转动；切换到两轮直接啮合，比较相反的输出转向。改变惰轮齿数可观察它的转速、轮径和轴间距变化，总速比大小仍由首尾齿数决定。公共视图、按钮和 AI 布局保持一致。

惰轮入门顺序：播放三轮传动 → 切直接啮合看方向 → 对比 20/30/40 与 20/50/40 齿 → 调整单次啮合效率看总效率。直接模式禁用并忽略惰轮齿数；三轮模式总效率为单次效率的平方。详见[惰轮齿轮列说明](meshlab/dist/idler/DESIGN.md)。

**[进入交叉平带实验](https://slack-zh.github.io/meshlab/belt.html)**：切换交叉平带与开口带对照，观察反向和同向传动。调整有效轮径、中心距、带宽及转速，三维带路同步变化；下方显示理论速比、带速、包角、投影带长、转矩和功率。视图、按钮和 AI 布局沿用已有实验。

平带入门顺序：播放交叉传动 → 切开口带比较转向 → 调轮径与中心距 → 看包角和投影带长 → 调整转矩、效率并提问。带长采用平面投影理论值，不包含交叉处显示避让；详见[平带模型说明](meshlab/dist/belt/DESIGN.md)。

**[进入同步带实验](https://slack-zh.github.io/meshlab/timing.html)**：观察带齿与带轮轮槽逐齿配合，调整两轮齿数验证同向速比。固定节距 5 mm；改变目标中心距后，选择最近的整数带齿数，再反求实际中心距。视图、操作按钮和 AI 布局保持一致。

同步带入门顺序：播放并看正视图 → 比较 20/40、30/30、40/20 齿 → 调目标中心距查看带齿数与实际值 → 调带宽、转矩和效率。模型采用 T5 梯形齿启发的教学轮廓，未声明产品标准认证；详见[同步带模型说明](meshlab/dist/timing/DESIGN.md)。

**[进入丝杠螺母实验](https://slack-zh.github.io/meshlab/vice.html)**：用台虎钳观察单线导程、丝杠转数与钳口位移。默认半剖显示固定螺母，实时读取开口、相对中位位移和圈数；切换张开/闭合保留位置，到行程端点自动停止。公共视图、按钮和 AI 布局保持一致。

丝杠入门顺序：从中位播放 → 改方向观察反向移动 → 比较 2、4、8 mm 导程 → 到端点后反向或复原。运动推力按给定效率和转矩估算，不表示端点静态夹紧力或额定承载；详见[台虎钳模型说明](meshlab/dist/vice/DESIGN.md)。

## 35 项机械机构扩展目录

新增清单第 24–34、36–37、39–60 项，共 **35 个独立参数化实验**；清单中已有制作人的第 35、38 项未纳入本批。原有减速器、汽轮机及链带等实验继续保留。

从首页的「机构目录」按名称搜索，或直接进入 [扩展机构实验](https://slack-zh.github.io/meshlab/catalog.html?model=universal-joint)。模型下方可切换机构、调整参数和查看实时结果；播放、速度、爆炸展开、复原、逐步拆装、零件目录及 AI 助手沿用已有实验的界面布局。完整编号、名称与直达 ID 见 [35 项能力简表](meshlab/dist/catalog/README.md)。

建议顺序：播放观察 → 一次改一个参数 → 查看原理和模型范围 → 展开并选取零件 → 向 AI 询问本次工况。1× 演示为输入工况的 20% 慢放；调转速保留相位，其他参数变化暂停并重建到初始相位。有限行程模型在端点夹停，复原后重新开始。

这些是运动与结构教学模型，各项的具体简化、公式和一手来源可在页面「资料」查看，不作为制造图样或额定承载证明。AI 保存提问时的模型、参数、运行状态与选中零件；原生目录上下文须由已部署后端的健康检查确认支持，纯静态预览不提供聊天 API。

在产品目录执行维护命令：

```sh
cd meshlab
npm run test:catalog
npm run build:catalog
```

测试命令运行四组目录模型和集成测试，不发出付费模型请求；构建命令重新生成扩展实验页、首页机构目录与目录索引。普通浏览已提交的网站无需执行构建。

## 怎么用

1. **认识零件**。进入实验室的「探索」页，拖动模型旋转，用滚轮或双指缩放。点击模型或打开「零件目录」，可在 49 个零件中查看名称、材料和作用，并播放中文讲解。
2. **观察装配**。拖动「爆炸展开」滑块查看零件之间的位置关系。切换到「逐步拆装」，按七个步骤查看拆卸顺序，再逐步复原。
3. **理解传动**。播放传动动画，再切到「原理」查看两级各 4∶1 如何得到总传动比 16∶1。模型用慢放展示各轴之间的真实转速比例。
4. **向 AI 提问**。在「AI 助手」中用邮箱注册或登录，选中零件后提问，助手会收到当前零件的上下文。可以从「输入齿轮轴的作用是什么？」开始。
5. **下载资料**。在「资料」页获取 STEP 装配和零件模型、PDF 图纸与设计说明书、BOM、设计参数和完整工程包。

## 本地运行

从仓库根目录启动静态预览。网页和 Three.js 资源随仓库提供，无需构建。

```sh
python -m http.server 8080 --directory meshlab/dist
```

浏览器打开 [本地首页](http://127.0.0.1:8080/) 或 [本地实验室](http://127.0.0.1:8080/lab.html)。浏览器需支持 WebGL，网页通过本地 HTTP 服务加载模型。

如果要使用 AI 助手，停止上述静态服务，再从仓库根目录用 Node.js 启动本地代理（推荐 24.14+，支持读取 Windows 已有系统代理）。它通过 Cloudflare Worker 使用与线上相同的账号和预算。

```sh
cd meshlab
node --env-file-if-exists=.env server/local.mjs
```

## AI 协作与任务交接

执行账号从 [任务队列](https://github.com/Slack-ZH/meshlab/blob/handoff/handoff/README.md) 找到待办，再阅读对应任务单。任务单包含改动范围、实施建议、验收标准，以及此次要提交的截图或测试结果。

规划账号负责把仓库维护者的需求写进任务队列，并按标准检查 PR。执行账号从任务单指定的基准开工作分支，完成实现和验证，再向 `main` 提交草稿 PR，按任务单回传结果。合并由仓库维护者决定。具体流程见 [交接说明](handoff/README.md)。
